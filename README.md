# HTML Forms Practice

This project demonstrates basic HTML form elements.

## Features
- Radio buttons
- Checkboxes
- Text input fields
- Submit button
- Proper use of labels and inputs

## Purpose
The purpose of this project is to practice and understand how HTML forms work.

## How to Use
1. Download or clone the repository.
2. Open the `index.html` file in a web browser.
